# Ricardo.ch Telegram Monitor Bot

Telegram-бот (на русском языке) для мониторинга новых объявлений на [ricardo.ch](https://www.ricardo.ch) с уведомлениями по заданным фильтрам.

## Как работает

Бот обходит страницы категорий и поиска Ricardo.ch (10 URL, случайная ротация), извлекает список объявлений из встроенного JSON `__NEXT_DATA__` (Next.js). Используется рекурсивный обходчик JSON — объявления находятся по наличию полей `id`+`title`, независимо от точной структуры.

Для каждого найденного объявления:
1. Загружается страница с деталями (если нужно дополнить данные)
2. Загружается профиль продавца с `https://www.ricardo.ch/de/shop/{ник}/ratings/` (дата регистрации, статистика)
3. Применяются пользовательские фильтры → подходящие объявления отправляются в Telegram

## Функции

- **Кнопки управления** — 🔍 Начать поиск / ⏹ Остановить поиск / ⚙️ Фильтры
- **Диапазон цен** — минимальная и/или максимальная цена в CHF
- **Дата регистрации продавца** — только продавцы, зарегистрированные до указанной даты
- **Дата публикации товара (от / до)** — диапазон дат/времени публикации объявления
- **Минимум продаж у продавца** — только продавцы с не менее X продажами
- **Минимум покупок у продавца** — только продавцы с не менее X покупками
- Непрерывный поиск с паузой ~5 секунд между батчами запросов

## Требования

- Python 3.11+
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

## Установка

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Настроить окружение
cp .env.example .env
# Открыть .env и задать TELEGRAM_BOT_TOKEN

# 3. Запустить бота
python bot.py
```

## Управление

| Кнопка / Команда | Описание |
|---|---|
| 🔍 Начать поиск | Запустить непрерывный поиск объявлений |
| ⏹ Остановить поиск | Остановить поиск |
| ⚙️ Фильтры | Открыть меню настройки фильтров |
| `/start` | Приветственное сообщение и показ кнопок |
| `/stop` | Остановить поиск (команда-псевдоним) |
| `/filter` | Открыть меню настройки фильтров |
| `/cancel` | Отменить текущее действие |

## Параметры фильтров

| Фильтр | Описание | Пример |
|---|---|---|
| Цена от | Минимальная цена в CHF | `50` |
| Цена до | Максимальная цена в CHF | `500` |
| Продавец зарегистрирован до | Только продавцы, зарег. до этой даты | `2023-01-01` или `2023` |
| Публикация от | Объявления, опубликованные после этой даты/времени | `2024-01-15 09:00` |
| Публикация до | Объявления, опубликованные до этой даты/времени | `2024-12-31 23:59` |
| Продано мин. | Минимальное кол-во продаж у продавца | `10` |
| Покупок мин. | Минимальное кол-во покупок у продавца | `5` |

## Примечания

- Данные хранятся в `parser.db` (SQLite) в текущей директории.
- Просмотренные объявления автоматически удаляются через 30 дней.
- Парсер извлекает данные из встроенного JSON (`__NEXT_DATA__`) страниц Ricardo.ch (Next.js), используя HTML-парсинг через BeautifulSoup как резервный метод.
