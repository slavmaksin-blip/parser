# Ricardo.ch Telegram Monitor Bot

Telegram-бот (на русском языке) для мониторинга новых объявлений на [ricardo.ch](https://www.ricardo.ch) с уведомлениями по заданным фильтрам.

## Как работает

Бот использует **два режима поиска** (автоматически переключается):

### 1. Поиск по ключевым словам / категориям (основной)
Если настроены ключевые слова или категории, бот выполняет поиск через URL:
`https://www.ricardo.ch/de/s/{keyword}/?sort=newest&priceFrom={min}&priceTo={max}`

Найденные ID объявлений затем полностью обрабатываются (заголовок, цена, продавец и т.д.).

### 2. Перебор случайных ID (резервный)
Если ключевые слова не заданы, бот генерирует случайные 10-значные ID в диапазоне **131xxxxxxx** (`1310000000–1319999999`) и обходит URL:
`https://www.ricardo.ch/de/a/{ID}/`

Оба режима поддерживают все фильтры и отправляют уведомления с инлайн-кнопками.

Извлекаемые данные:
- **Название, цена, категория, состояние, тип объявления**
- **Дата публикации, дата окончания** (для аукционов)
- **Продавец** — ник, дата регистрации, количество продаж, рейтинг
- **Локация, варианты доставки**
- **Первое фото** объявления

## Функции

- **Кнопки управления** — 🔍 Начать / ⏹ Остановить / ⚙️ Фильтры / 📊 Статус
- **Фильтры**: ключевые слова, категория, диапазон цен, тип (Sofortkauf/Auktion/Festpreis), состояние, локация, доставка, дата регистрации продавца, мин. продаж
- **Уведомления** с кнопками «Открыть на Ricardo» и «Скрыть»
- **Ротация User-Agent** и случайные задержки 0.5–2 с (защита от блокировки)
- **Интервал мониторинга**: 30–90 секунд между циклами
- **Макс. 5 уведомлений** за один цикл

## Требования

- Python 3.11+
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

## Установка

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Настроить окружение
cp .env.example .env
# Открыть .env и задать TELEGRAM_BOT_TOKEN

# 3. Запустить бота
python bot.py
```

## Управление

| Кнопка / Команда | Описание |
|---|---|
| 🔍 Начать поиск | Запустить непрерывный мониторинг |
| ⏹ Остановить поиск | Остановить мониторинг |
| ⚙️ Фильтры | Открыть меню настройки фильтров |
| 📊 Статус | Показать текущие фильтры и статус |
| `/start` | Приветственное сообщение |
| `/stop` | Остановить мониторинг |
| `/filters` | Открыть меню фильтров |
| `/add` | Настроить фильтры (псевдоним) |
| `/status` | Статус мониторинга |

## Параметры фильтров

| Фильтр | Описание | Пример |
|---|---|---|
| Ключевые слова | Поиск по тексту | `iPhone 14 Pro` |
| Категория | Выбор из дерева категорий Ricardo.ch | `Smartphones` |
| Цена от / до | Диапазон цены в CHF | `100` / `800` |
| Тип объявления | Sofortkauf / Auktion / Festpreis | `Sofortkauf` |
| Состояние | Neu / Gebraucht / Wie neu / Defekt | `Neu` |
| Локация | Текст для поиска в поле города | `Zürich` |
| Доставка | Versand / Abholung | `Versand` |
| Продавец зарег. до | Только продавцы, зарег. до этой даты | `2023-01-01` |
| Мин. продаж | Минимум продаж у продавца | `50` |

## Структура проекта

```
parser/
├── bot.py          # Telegram-бот на aiogram 3.x (точка входа)
├── scraper.py      # Асинхронный парсер Ricardo.ch (keyword search + ID probe)
├── db.py           # База данных SQLite (aiosqlite)
├── requirements.txt
├── .env.example
└── README.md
```

## Примечания

- Данные хранятся в `parser.db` (SQLite) в текущей директории.
- Просмотренные объявления автоматически удаляются через 30 дней.
- Парсер извлекает данные из встроенного JSON (`__NEXT_DATA__`) страниц Ricardo.ch (Next.js), используя HTML-парсинг через BeautifulSoup как резервный метод.
